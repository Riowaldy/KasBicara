Kebijakan Privasi

Berlaku sejak 8 Agustus 2026

Ringkasan singkat

  • Data keuangan Anda disimpan hanya di perangkat Anda, terenkripsi — tidak ada server KasBicara yang menyimpan atau melihatnya.
  • Tidak ada akun/login — KasBicara tidak mengenal identitas Anda.
  • Mikrofon dipakai sekadar mengubah ucapan jadi teks transaksi — audio tidak disimpan oleh KasBicara.
  • Tidak dijual atau dibagikan ke pihak ketiga. Data hanya keluar dari perangkat kalau Anda sendiri menekan tombol ekspor/bagikan.
  • Hapus aplikasi = hapus semua data — tidak ada salinan tersimpan di tempat lain.

01Data yang Kami Kumpulkan

KasBicara mencatat transaksi keuangan yang Anda masukkan sendiri, baik lewat suara maupun ketik manual. Data yang tersimpan hanya:

  • Jenis transaksi (masuk/keluar), jumlah, kategori, keterangan, dan tanggal.
  • Kategori transaksi (bawaan aplikasi atau yang Anda buat sendiri).

KasBicara tidak meminta nama, email, nomor telepon, lokasi, kontak, atau identitas pribadi lain untuk bisa dipakai — tidak ada proses pendaftaran akun sama sekali.

02Bagaimana Data Digunakan

Data transaksi yang Anda catat dipakai semata-mata untuk menjalankan fungsi aplikasi di perangkat Anda sendiri: menghitung saldo, menampilkan riwayat, menyusun grafik ringkasan di Dashboard, dan menyiapkan file ekspor Excel/PDF ketika diminta.

KasBicara tidak memakai data Anda untuk iklan, analitik pihak ketiga, atau pelatihan model apa pun. Tidak ada SDK pelacak (tracking) yang tertanam di aplikasi ini.

03Penyimpanan & Keamanan

Lokal di perangkat Terenkripsi (AES, SQLCipher) Tanpa server KasBicara

Seluruh data transaksi disimpan dalam database terenkripsi (SQLCipher) langsung di penyimpanan internal perangkat Anda. Kunci enkripsinya sendiri disimpan lewat mekanisme keamanan sistem operasi (Android Keystore) — bukan di dalam kode aplikasi maupun dikirim ke mana pun.

Karena tidak ada server backend, KasBicara secara teknis tidak memiliki cara untuk mengakses data Anda dari luar perangkat Anda.

04Akses Mikrofon & Pengenalan Suara

Saat Anda menekan tombol mikrofon, KasBicara meminta izin mikrofon untuk merekam ucapan Anda secara sementara dan mengubahnya menjadi teks, memakai layanan pengenalan suara bawaan sistem operasi perangkat Anda (mesin speech-to-text Android/iOS).

Bergantung pada pengaturan perangkat, proses pengubahan suara-ke-teks ini bisa berjalan sepenuhnya di perangkat (on-device) atau memakai layanan cloud milik penyedia sistem operasi (mis. Google) — ini di luar kendali KasBicara, dan tunduk pada kebijakan privasi penyedia sistem operasi tersebut, bukan kebijakan ini.

KasBicara sendiri tidak merekam maupun menyimpan file audio Anda. Hanya teks hasil transkripsi yang diproses sesaat untuk mengisi draf transaksi — dan teks itu pun tidak disimpan terpisah, hanya dipakai untuk mengisi field yang kemudian Anda konfirmasi atau ubah sebelum disimpan sebagai transaksi.

05Berbagi Data

KasBicara tidak pernah mengirim data Anda ke pihak mana pun secara otomatis. Satu-satunya cara data keluar dari aplikasi adalah ketika Anda sendiri menekan tombol "Export Excel" atau "Export PDF", lalu memilih tujuan berbagi lewat menu bagikan bawaan perangkat (mis. email, WhatsApp, Google Drive).

Begitu file itu Anda bagikan lewat aplikasi lain, penggunaan selanjutnya tunduk pada kebijakan privasi aplikasi/layanan tujuan tersebut, bukan kebijakan ini.

06Hak Anda atas Data

Karena semua data ada di perangkat Anda, Anda memegang kendali penuh:

  • Hapus transaksi kapan saja langsung dari layar Riwayat.
  • Hapus seluruh data sekaligus dengan mencopot pemasangan (uninstall) aplikasi — tidak ada salinan yang tertinggal di server mana pun, karena memang tidak ada server.

07Privasi Anak

KasBicara tidak ditujukan untuk anak di bawah 13 tahun dan tidak dirancang untuk mengumpulkan data dari mereka secara sadar. Karena aplikasi ini tidak meminta data pribadi apa pun dan tidak memiliki fitur akun, risiko pengumpulan data anak secara tidak sengaja sangat minim.

08Perubahan Kebijakan Ini

Jika suatu saat KasBicara menambah fitur yang mengubah cara data ditangani (misalnya sinkronisasi cloud opsional di versi mendatang), kebijakan ini akan diperbarui dan tanggal "Berlaku sejak" di atas akan disesuaikan sebelum fitur tersebut aktif.
