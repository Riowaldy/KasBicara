# KasBicara

**KasBicara** adalah aplikasi mobile pencatatan keuangan pribadi berbasis **suara**, dibangun dengan Flutter (Android & iOS). Pengguna dapat mencatat transaksi uang masuk/keluar cukup dengan berbicara — aplikasi akan mengubah ucapan menjadi entri transaksi terstruktur (jenis, jumlah, kategori, keterangan) yang dapat dikoreksi sebelum disimpan.

## Status

Proyek masih dalam tahap perencanaan awal. Implementasi kode Flutter belum dimulai.

## Ringkasan Fitur (MVP)

- Input transaksi via suara (Bahasa Indonesia) dengan parsing otomatis jenis, jumlah, dan kategori.
- Layar konfirmasi/edit sebelum transaksi disimpan.
- Input manual (form) sebagai alternatif/pelengkap suara.
- Manajemen kategori transaksi (default + kustom).
- Dashboard: saldo saat ini, ringkasan bulanan, grafik kategori & tren.
- Riwayat transaksi dengan filter dan opsi hapus/edit.
- Ekspor laporan ke Excel (.xlsx) dan PDF.
- Penyimpanan data lokal di perangkat (offline-first).
